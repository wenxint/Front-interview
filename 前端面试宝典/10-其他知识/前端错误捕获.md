# 前端错误捕获方法详解

在前端开发中，错误捕获和处理是保障应用稳定性和用户体验的重要环节。本文将详细介绍前端错误捕获的各种方法。

## 一、前端错误类型

前端错误主要分为以下几类：

1. **JavaScript运行时错误**：代码执行过程中出现的语法错误、类型错误等
2. **资源加载错误**：图片、CSS、JS等静态资源加载失败
3. **网络请求错误**：Ajax请求失败、跨域问题等
4. **Promise错误**：未处理的Promise拒绝
5. **框架错误**：React/Vue等框架内部错误

## 二、全局错误捕获

### 1. window.onerror

这是最基础的全局错误捕获方法：

```javascript
window.onerror = function(message, source, lineno, colno, error) {
  console.log('错误信息:', message);
  console.log('错误文件:', source);
  console.log('错误行号:', lineno);
  console.log('错误列号:', colno);
  console.log('错误对象:', error);
  
  // 上报错误到服务器
  reportError({
    message,
    source,
    lineno,
    colno,
    stack: error.stack
  });
  
  // 返回true表示错误已处理，浏览器不会在控制台输出错误
  return true;
};
```

**注意**：
- 只能捕获JavaScript运行时错误
- 无法捕获Promise错误
- 无法捕获网络资源加载错误

### 2. addEventListener('error')

用于捕获资源加载错误：

```javascript
window.addEventListener('error', function(event) {
  // 判断是否为资源加载错误
  if (event.target !== window) {
    console.log('资源加载错误:', {
      element: event.target,
      url: event.target.src || event.target.href
    });
    
    // 上报资源加载错误
    reportResourceError({
      url: event.target.src || event.target.href,
      tagName: event.target.tagName
    });
  } else {
    // JavaScript运行时错误
    console.log('JavaScript错误:', event.error);
  }
}, true); // 使用捕获阶段
```

### 3. unhandledrejection

用于捕获未处理的Promise拒绝：

```javascript
window.addEventListener('unhandledrejection', function(event) {
  console.log('未处理的Promise拒绝:', event.reason);
  
  // 上报Promise错误
  reportPromiseError(event.reason);
  
  // 阻止默认行为（在控制台输出错误）
  event.preventDefault();
});
```

## 三、try/catch

对于可预见的错误，使用try/catch进行局部捕获：

```javascript
try {
  // 可能出错的代码
  JSON.parse(jsonString);
} catch (error) {
  console.log('JSON解析错误:', error.message);
  // 处理错误
  handleJSONError(error);
}

// 异步代码中的错误捕获
async function fetchData() {
  try {
    const response = await fetch('/api/data');
    const data = await response.json();
    return data;
  } catch (error) {
    console.log('请求失败:', error.message);
    // 处理错误
    handleFetchError(error);
  }
}
```

## 四、框架级错误处理

### 1. React错误边界

```jsx
class ErrorBoundary extends React.Component {
  constructor(props) {
    super(props);
    this.state = { hasError: false };
  }

  static getDerivedStateFromError(error) {
    // 更新state使下一次渲染可以显示降级UI
    return { hasError: true };
  }

  componentDidCatch(error, errorInfo) {
    // 记录错误信息
    console.log('组件错误:', error, errorInfo);
    
    // 上报错误到服务器
    reportReactError(error, errorInfo);
  }

  render() {
    if (this.state.hasError) {
      // 显示降级UI
      return <h1>Something went wrong.</h1>;
    }

    return this.props.children;
  }
}

// 使用方式
<ErrorBoundary>
  <MyWidget />
</ErrorBoundary>
```

### 2. Vue错误处理

```javascript
// 全局错误处理
Vue.config.errorHandler = function(err, vm, info) {
  console.log('Vue错误:', err, vm, info);
  
  // 上报错误
  reportVueError(err, vm, info);
};

// 生命周期钩子中的错误捕获
export default {
  async mounted() {
    try {
      await this.fetchData();
    } catch (error) {
      console.log('数据获取失败:', error);
      this.$message.error('数据加载失败');
    }
  }
};
```

## 五、异步错误处理

### 1. Promise错误处理

```javascript
// 使用catch处理Promise错误
fetch('/api/data')
  .then(response => response.json())
  .then(data => {
    // 处理数据
    console.log(data);
  })
  .catch(error => {
    console.log('请求失败:', error);
    // 处理错误
  });

// async/await中的错误处理
async function handleAsyncOperation() {
  try {
    const result = await riskyOperation();
    return result;
  } catch (error) {
    console.log('异步操作失败:', error);
    throw error; // 重新抛出错误
  }
}
```

### 2. 定时器错误处理

```javascript
// 包装定时器函数
function safeSetTimeout(fn, delay) {
  return setTimeout(() => {
    try {
      fn();
    } catch (error) {
      console.log('定时器错误:', error);
      reportError(error);
    }
  }, delay);
}

// 使用方式
safeSetTimeout(() => {
  // 可能出错的代码
  riskyOperation();
}, 1000);
```

## 六、资源和网络错误处理

### 1. 图片加载错误

```javascript
// 为所有图片添加错误处理
document.addEventListener('error', function(event) {
  if (event.target.tagName === 'IMG') {
    // 替换为默认图片
    event.target.src = '/images/default.png';
    console.log('图片加载失败:', event.target.src);
  }
}, true);
```

### 2. Fetch请求错误处理

```javascript
async function fetchWithTimeout(url, options = {}) {
  const { timeout = 5000 } = options;
  
  const controller = new AbortController();
  const id = setTimeout(() => controller.abort(), timeout);
  
  try {
    const response = await fetch(url, {
      ...options,
      signal: controller.signal
    });
    clearTimeout(id);
    
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}: ${response.statusText}`);
    }
    
    return response;
  } catch (error) {
    clearTimeout(id);
    
    if (error.name === 'AbortError') {
      throw new Error('请求超时');
    }
    
    throw error;
  }
}
```

## 七、错误上报机制

### 1. 基础错误上报

```javascript
class ErrorReporter {
  constructor(options = {}) {
    this.url = options.url || '/api/errors';
    this.queue = [];
    this.sending = false;
  }
  
  report(errorInfo) {
    this.queue.push({
      ...errorInfo,
      timestamp: Date.now(),
      userAgent: navigator.userAgent,
      url: location.href
    });
    
    this.send();
  }
  
  async send() {
    if (this.sending || this.queue.length === 0) {
      return;
    }
    
    this.sending = true;
    
    try {
      const errors = this.queue.splice(0, 10); // 批量发送
      await fetch(this.url, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({ errors })
      });
    } catch (error) {
      console.log('错误上报失败:', error);
    } finally {
      this.sending = false;
      
      // 如果还有未发送的错误，继续发送
      if (this.queue.length > 0) {
        setTimeout(() => this.send(), 1000);
      }
    }
  }
}

const errorReporter = new ErrorReporter();

// 全局错误捕获
window.onerror = function(message, source, lineno, colno, error) {
  errorReporter.report({
    type: 'javascript',
    message,
    source,
    lineno,
    colno,
    stack: error?.stack
  });
  
  return true;
};
```

## 八、面试重点

1. **window.onerror与addEventListener('error')的区别**
   - window.onerror只能捕获JavaScript运行时错误
   - addEventListener('error')可以捕获资源加载错误

2. **Promise错误捕获方法**
   - 使用catch方法
   - 使用unhandledrejection事件

3. **React/Vue框架错误处理机制**
   - React错误边界(Error Boundary)
   - Vue全局错误处理器

4. **错误上报策略**
   - 批量上报
   - 重试机制
   - 用户信息收集

5. **性能优化考虑**
   - 避免频繁上报
   - 错误去重
   - 采样上报

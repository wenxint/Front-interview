# 前端页面性能指标详解

## 核心性能指标

### 1. 白屏时间 (First Paint, FP)

**定义**：
白屏时间是指从用户访问页面到浏览器开始绘制第一个像素的时间。这是用户感知页面加载速度的第一个重要指标。

**计算方法**：
使用 Navigation Timing API 计算：

```javascript
const fp = performance.getEntriesByType('paint')[0].startTime;
console.log(`白屏时间: ${fp} ms`);
```

### 2. 首次内容绘制 (First Contentful Paint, FCP)

**定义**：
FCP 衡量的是页面首次绘制任何文本、图像、非白色背景等内容的时间。

**计算方法**：
使用 Paint Timing API 计算：

```javascript
const fcp = performance.getEntriesByType('paint')[1].startTime;
console.log(`首次内容绘制时间: ${fcp} ms`);
```

### 3. 可交互时间 (Time to Interactive, TTI)

**定义**：
TTI 衡量的是页面布局已稳定、关键的资源已加载完成、且用户可以与页面进行交互的时间。

**计算方法**：
使用 Performance API 计算：

```javascript
function calculateTTI() {
  // 这是一个简化的计算方式
  // 实际应用中可能需要更复杂的算法
  const tti = performance.getEntriesByType('navigation')[0].domContentLoadedEventEnd;
  console.log(`可交互时间: ${tti} ms`);
}
```

## 其他重要指标

### 4. 最大内容绘制 (Largest Contentful Paint, LCP)

**定义**：
LCP 衡量的是视口中最大的内容元素渲染完成的时间，这是衡量加载性能的重要指标。

**目标值**：最好在 2.5 秒内完成。

### 5. 首次输入延迟 (First Input Delay, FID)

**定义**：
FID 衡量的是用户第一次与页面交互（点击链接、按钮等）到浏览器实际开始处理该交互之间的时间差。  

**目标值**：最好在 100 毫秒内。

### 6. 累积布局偏移 (Cumulative Layout Shift, CLS)

**定义**：
CLS 衡量的是页面在生命周期内发生的意外布局偏移的总和，反映了页面的视觉稳定性。

**目标值**：最好控制在 0.1 以内。

## 性能监控实践

### 使用 Performance API 监控

```javascript
// 监控所有核心性能指标
function reportPerformanceMetrics() {
  // 等待页面加载完成
  if (document.readyState !== 'complete') {
    window.addEventListener('load', reportPerformanceMetrics);
    return;
  }

  // 获取 FP 和 FCP
  const paintEntries = performance.getEntriesByType('paint');
  paintEntries.forEach(entry => {
    console.log(`${entry.name}: ${entry.startTime} ms`);
  });

  // 获取 Navigation Timing 数据
  const navEntries = performance.getEntriesByType('navigation');
  navEntries.forEach(entry => {
    console.log('Navigation Timing:', entry);
  });
}

// 上报性能数据
reportPerformanceMetrics();
```

### 性能优化建议

1. **减少白屏时间**：
   - 优化服务器响应时间
   - 减少关键资源的大小
   - 优化 CSS 和 JavaScript 加载

2. **提升 FCP**：
   - 优化首屏内容的加载
   - 使用适当的图片格式和尺寸
   - 减少阻塞渲染的资源

3. **改善 TTI**：
   - 减少 JavaScript 执行时间
   - 使用代码分割
   - 优化第三方脚本

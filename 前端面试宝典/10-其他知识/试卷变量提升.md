# 变量提升试卷

## 一、选择题 (每题5分，共10题)

1. JavaScript中变量提升是指什么？
   A. 变量在声明前可以使用
   B. 变量在声明后自动提升到代码顶部
   C. 变量的值自动提升到全局作用域
   D. 变量的声明自动提升到作用域顶部

   **答案：D**
   **解析**：变量提升是指变量声明会被提升到作用域顶部，但赋值不会提升。

2. 以下代码的输出结果是什么？
   ```javascript
   console.log(a);
   var a = 5;
   ```
   A. 5
   B. undefined
   C. 报错
   D. null

   **答案：B**
   **解析**：变量a的声明被提升到顶部，但赋值不会提升，所以输出undefined。

3. 函数声明和函数表达式在变量提升方面有什么区别？
   A. 没有区别
   B. 函数声明会被提升，函数表达式不会
   C. 函数表达式会被提升，函数声明不会
   D. 两者都会被提升，但提升方式不同

   **答案：D**
   **解析**：函数声明整个都会被提升，而函数表达式只有变量声明被提升，函数体不会。

4. 以下代码的输出结果是什么？
   ```javascript
   console.log(foo);
   var foo = function() {
       console.log('foo');
   };
   ```
   A. function() { console.log('foo'); }
   B. undefined
   C. 报错
   D. foo

   **答案：B**
   **解析**：foo是函数表达式，只有变量声明被提升，函数体不会，所以输出undefined。

5. let和const声明的变量是否会发生变量提升？
   A. 会发生变量提升
   B. 不会发生变量提升
   C. 会发生变量提升，但不能在声明前使用
   D. 以上都不对

   **答案：C**
   **解析**：let和const也会发生变量提升，但在声明前使用会报错，称为暂时性死区。

6. 以下代码的输出结果是什么？
   ```javascript
   function bar() {
       console.log(a);
       var a = 10;
   }
   bar();
   ```
   A. 10
   B. undefined
   C. 报错
   D. null

   **答案：B**
   **解析**：变量a的声明被提升到函数作用域顶部，但赋值不会提升，所以输出undefined。

7. 以下代码的输出结果是什么？
   ```javascript
   console.log(baz);
   let baz = 5;
   ```
   A. 5
   B. undefined
   C. 报错
   D. null

   **答案：C**
   **解析**：let声明的变量虽然会提升，但在声明前访问会报错（暂时性死区）。

8. 以下代码的输出结果是什么？
   ```javascript
   function test() {
       console.log(func);
       function func() {
           console.log('func');
       }
   }
   test();
   ```
   A. function func() { console.log('func'); }
   B. undefined
   C. 报错
   D. func

   **答案：A**
   **解析**：函数声明会被完全提升，所以在声明前可以访问到函数。

9. 在同一作用域中，var声明和函数声明哪个优先级更高？
   A. var声明优先级更高
   B. 函数声明优先级更高
   C. 优先级相同
   D. 取决于声明顺序

   **答案：B**
   **解析**：在同一作用域中，函数声明的优先级高于var声明。

10. 以下代码的输出结果是什么？
    ```javascript
    console.log(qux);
    var qux = function qux() {
        console.log('qux');
    };
    ```
    A. function qux() { console.log('qux'); }
    B. undefined
    C. 报错
    D. qux

    **答案：B**
    **解析**：qux是函数表达式，只有变量声明被提升，函数体不会，所以输出undefined。

## 三、简答题 (每题10分，共5题)

16. 请解释JavaScript中的变量提升现象，并举例说明。

    **答案**：

    - 变量提升是指JavaScript引擎在代码执行前会先解析所有声明的变量和函数，将它们提升到作用域顶部。
    - 只有声明会被提升，赋值不会提升。
    - 例如：
      ```javascript
      console.log(a); // undefined
      var a = 5;
      console.log(a); // 5
      ```
      等价于：
      ```javascript
      var a;
      console.log(a); // undefined
      a = 5;
      console.log(a); // 5
      ```

17. 请说明var、let和const在变量提升方面的区别。

    **答案**：

    - var声明的变量会被提升到作用域顶部，初始值为undefined，可以在声明前访问。
    - let和const声明的变量也会被提升，但在声明前访问会报错（暂时性死区），必须先声明再使用。
    - var存在函数作用域或全局作用域，let和const存在块级作用域。
    - 例如：
      ```javascript
      console.log(a); // undefined
      var a = 1;
      
      console.log(b); // 报错
      let b = 2;
      
      console.log(c); // 报错
      const c = 3;
      ```

18. 请解释函数声明和函数表达式在变量提升上的区别，并举例说明。

    **答案**：

    - 函数声明会被完全提升，包括函数名和函数体，可以在声明前调用。
    - 函数表达式只有变量声明被提升，函数体不会被提升，必须在赋值后才能调用。
    - 例如：
      ```javascript
      // 函数声明
      foo(); // 可以正常调用
      function foo() {
          console.log('foo');
      }
      
      // 函数表达式
      bar(); // 报错
      var bar = function() {
          console.log('bar');
      };
      ```

19. 什么是暂时性死区（Temporal Dead Zone）？它与变量提升有什么关系？

    **答案**：

    - 暂时性死区是指在let或const声明变量之前的区域，在这个区域中访问变量会报错。
    - 它与变量提升的关系是：虽然let和const声明的变量也会被提升，但在声明前不能访问，形成了暂时性死区。
    - 这有助于避免在变量声明前意外使用变量。
    - 例如：
      ```javascript
      console.log(a); // 报错
      let a = 1;
      ```
      在let a声明之前，访问a就会报错，这段区域就是暂时性死区。

20. 请解释以下代码的执行结果，并说明原因：
    ```javascript
    var a = 1;
    function b() {
        a = 10;
        return;
        function a() {}
    }
    b();
    console.log(a);
    ```

    **答案**：

    - 输出结果：1
    - 原因：
      1. 函数b内部的function a() {}声明会被提升到函数b的顶部。
      2. 因此，在函数b内部，a是一个函数，而不是外部的变量a。
      3. a = 10;实际上是修改了函数a，而不是外部的变量a。
      4. 外部的变量a值仍然是1，所以console.log(a)输出1。

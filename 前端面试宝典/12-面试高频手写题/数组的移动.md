# 数组向前移动K位和向后移动K位实现

## 需求说明

- 实现数组向前移动K位和向后移动K位
- 空出来的位置用空字符串 `''` 补足
- 条件：K < arr.length
- 提供两种实现方式：slice方法 和 纯下标操作

## 方法一：使用slice方法实现

### 向前移动K位（元素向左移动）

```javascript
/**
 * 数组向前移动K位 - slice方法
 * @param {Array} arr - 原数组
 * @param {number} k - 移动位数
 * @returns {Array} - 移动后的新数组
 */
function moveForwardSlice(arr, k) {
  if (k >= arr.length || k <= 0) {
    throw new Error('K必须大于0且小于数组长度');
  }

  // 取从k位置开始到末尾的元素
  const movedElements = arr.slice(k);

  // 创建k个空字符串填充到末尾
  const emptySpaces = new Array(k).fill('');

  // 合并数组
  return [...movedElements, ...emptySpaces];
}

// 使用示例
const arr1 = ['a', 'b', 'c', 'd', 'e'];
console.log('原数组:', arr1);
console.log('向前移动2位:', moveForwardSlice(arr1, 2));
// 输出: ['c', 'd', 'e', '', '']
```

### 向后移动K位（元素向右移动）

```javascript
/**
 * 数组向后移动K位 - slice方法
 * @param {Array} arr - 原数组
 * @param {number} k - 移动位数
 * @returns {Array} - 移动后的新数组
 */
function moveBackwardSlice(arr, k) {
  if (k >= arr.length || k <= 0) {
    throw new Error('K必须大于0且小于数组长度');
  }

  // 创建k个空字符串填充到开头
  const emptySpaces = new Array(k).fill('');

  // 取从开头到length-k位置的元素
  const movedElements = arr.slice(0, arr.length - k);

  // 合并数组
  return [...emptySpaces, ...movedElements];
}

// 使用示例
const arr2 = ['a', 'b', 'c', 'd', 'e'];
console.log('原数组:', arr2);
console.log('向后移动2位:', moveBackwardSlice(arr2, 2));
// 输出: ['', '', 'a', 'b', 'c']
```

## 方法二：使用纯下标操作实现（优化版）

### 向前移动K位（元素向左移动）

```javascript
/**
 * 数组向前移动K位 - 优化的纯下标方法
 * @param {Array} arr - 原数组
 * @param {number} k - 移动位数
 * @returns {Array} - 移动后的新数组
 */
function moveForwardIndex(arr, k) {
  if (k >= arr.length || k <= 0) {
    throw new Error('K必须大于0且小于数组长度');
  }

  // 创建与原数组相同长度的新数组，全部填充为空字符串
  const result = new Array(arr.length).fill('');

  // 将原数组从k位置开始的元素移动到新数组的开头
  for (let i = 0; i < arr.length - k; i++) {
    result[i] = arr[i + k];
  }

  return result;
}

// 使用示例
const arr3 = ['a', 'b', 'c', 'd', 'e'];
console.log('原数组:', arr3);
console.log('向前移动2位:', moveForwardIndex(arr3, 2));
// 输出: ['c', 'd', 'e', '', '']
```

### 向后移动K位（元素向右移动）

```javascript
/**
 * 数组向后移动K位 - 优化的纯下标方法
 * @param {Array} arr - 原数组
 * @param {number} k - 移动位数
 * @returns {Array} - 移动后的新数组
 */
function moveBackwardIndex(arr, k) {
  if (k >= arr.length || k <= 0) {
    throw new Error('K必须大于0且小于数组长度');
  }

  // 创建与原数组相同长度的新数组，全部填充为空字符串
  const result = new Array(arr.length).fill('');

  // 将原数组的前length-k个元素移动到新数组的k位置之后
  for (let i = 0; i < arr.length - k; i++) {
    result[i + k] = arr[i];
  }

  return result;
}

// 使用示例
const arr4 = ['a', 'b', 'c', 'd', 'e'];
console.log('原数组:', arr4);
console.log('向后移动2位:', moveBackwardIndex(arr4, 2));
// 输出: ['', '', 'a', 'b', 'c']
```

## 优化效果对比

### 优化前（需要两个循环）：
```javascript
const result = new Array(arr.length);
// 第一个循环：移动元素
for (let i = 0; i < arr.length - k; i++) {
  result[i] = arr[i + k];
}
// 第二个循环：填充空字符串
for (let i = arr.length - k; i < arr.length; i++) {
  result[i] = '';
}
```

### 优化后（只需要一个循环）：
```javascript
const result = new Array(arr.length).fill('');
// 一个循环：只移动元素，其他位置已经是空字符串
for (let i = 0; i < arr.length - k; i++) {
  result[i] = arr[i + k];
}
```

## 性能对比

### 时间复杂度
- **slice方法**: O(n) - slice操作本身是O(n)，数组合并也是O(n)
- **优化的下标方法**: O(n) - 单次遍历，直接赋值

### 空间复杂度
- **slice方法**: O(n) - 创建了临时数组和最终结果数组
- **优化的下标方法**: O(n) - 只创建了最终结果数组

### 优化优势
1. **代码更简洁**：减少了一个循环
2. **逻辑更清晰**：先填充空字符串，再覆盖需要的位置
3. **性能略好**：`fill('')` 是原生方法，比手动循环填充效率更高
4. **可读性更强**：意图更明确

### 性能建议
- 对于小数组，两种方法性能差异不大
- 对于大数组，优化的下标方法更优，因为减少了临时数组的创建和循环次数
- slice方法代码更简洁易读，优化的下标方法更节省内存且性能更好

## 原地操作实现（避免临时数组）

以上方法都会创建新数组，如果需要在原数组上直接修改（原地操作），可以使用以下方法：

### 原地操作的核心概念

**原地操作**是指直接在原数组上进行修改，不创建新的数组，这样可以节省内存空间。但是在移动过程中需要特别注意**避免覆盖未处理的数据**。

### 向前移动K位的原地操作

```javascript
/**
 * 数组向前移动K位 - 原地操作
 * @param {Array} arr - 原数组（会被直接修改）
 * @param {number} k - 移动位数
 * @returns {Array} - 修改后的原数组
 */
function moveForwardInPlace(arr, k) {
  if (k >= arr.length || k <= 0) {
    throw new Error('K必须大于0且小于数组长度');
  }

  // 1. 从前往后移动元素（安全，不会覆盖未处理的数据）
  for (let i = 0; i < arr.length - k; i++) {
    arr[i] = arr[i + k];  // 从右边读取，写入左边
  }

  // 2. 将后面K个位置填充为空字符串
  for (let i = arr.length - k; i < arr.length; i++) {
    arr[i] = '';
  }

  return arr;
}

// 使用示例
const arr5 = ['a', 'b', 'c', 'd', 'e'];
console.log('原数组:', [...arr5]);
console.log('向前移动2位:', moveForwardInPlace(arr5, 2));
// 输出: ['c', 'd', 'e', '', '']
// 注意：原数组已被修改
```

### 向后移动K位的原地操作 - 关键：从后往前处理

```javascript
/**
 * 数组向后移动K位 - 原地操作
 * @param {Array} arr - 原数组（会被直接修改）
 * @param {number} k - 移动位数
 * @returns {Array} - 修改后的原数组
 */
function moveBackwardInPlace(arr, k) {
  if (k >= arr.length || k <= 0) {
    throw new Error('K必须大于0且小于数组长度');
  }

  // 关键：必须从后往前移动，避免覆盖未处理的数据
  for (let i = arr.length - k - 1; i >= 0; i--) {
    arr[i + k] = arr[i];  // 从左边读取，写入右边
  }

  // 将前面K个位置填充为空字符串
  for (let i = 0; i < k; i++) {
    arr[i] = '';
  }

  return arr;
}

// 使用示例
const arr6 = ['a', 'b', 'c', 'd', 'e'];
console.log('原数组:', [...arr6]);
console.log('向后移动2位:', moveBackwardInPlace(arr6, 2));
// 输出: ['', '', 'a', 'b', 'c']
// 注意：原数组已被修改
```

### 为什么向后移动必须从后往前处理？

这是原地操作中最关键的概念，让我们通过具体例子来理解：

#### 错误示例：从前往后移动（会导致数据覆盖）

```javascript
// 原数组：['a', 'b', 'c', 'd', 'e']，向后移动2位
// 期望结果：['', '', 'a', 'b', 'c']

// ❌ 错误的从前往后移动：
// 第1步：arr[2] = arr[0] = 'a'  →  ['a', 'b', 'a', 'd', 'e']
// 第2步：arr[3] = arr[1] = 'b'  →  ['a', 'b', 'a', 'b', 'e']
// 第3步：arr[4] = arr[2] = 'a'  →  ['a', 'b', 'a', 'b', 'a']
//        ↑ 问题：arr[2]已经被覆盖成'a'了，原来的'c'丢失了！

// 最终错误结果：['', '', 'a', 'b', 'a']  // 'c'丢失了
```

#### 正确示例：从后往前移动（保护数据不被覆盖）

```javascript
// 原数组：['a', 'b', 'c', 'd', 'e']，向后移动2位
// 期望结果：['', '', 'a', 'b', 'c']

// ✅ 正确的从后往前移动：
// 第1步：arr[4] = arr[2] = 'c'  →  ['a', 'b', 'c', 'd', 'c']
// 第2步：arr[3] = arr[1] = 'b'  →  ['a', 'b', 'c', 'b', 'c']
// 第3步：arr[2] = arr[0] = 'a'  →  ['a', 'b', 'a', 'b', 'c']
//        ↑ 正确：先处理后面的元素，读取的数据不会被覆盖

// 最后填充前面的空位：
// arr[0] = '', arr[1] = ''  →  ['', '', a, b, c]
// 最终正确结果：['', '', 'a', 'b', 'c']
```

### 覆盖问题的图解说明

```
向后移动2位的过程分析：

原数组：[a, b, c, d, e]
索引：  0  1  2  3  4

目标：  ['', '', a, b, c]
索引：   0   1  2  3  4

如果从前往后移动：
步骤1：arr[2] = arr[0]  →  [a, b, a, d, e]  // c被覆盖了！
步骤2：arr[3] = arr[1]  →  [a, b, a, b, e]  // d被覆盖了！
步骤3：arr[4] = arr[2]  →  [a, b, a, b, a]  // 读到的是覆盖后的a，不是原来的c

如果从后往前移动：
步骤1：arr[4] = arr[2]  →  [a, b, c, d, c]  // 先保存c
步骤2：arr[3] = arr[1]  →  [a, b, c, b, c]  // 再保存b
步骤3：arr[2] = arr[0]  →  [a, b, a, b, c]  // 最后保存a
填充：  arr[0]='', arr[1]=''  →  ['', '', a, b, c]  // 完成
```

### 原地操作的优化版本（无临时数组）

```javascript
/**
 * 数组向后移动K位 - 无临时数组的原地操作
 * @param {Array} arr - 原数组（会被直接修改）
 * @param {number} k - 移动位数
 * @returns {Array} - 修改后的原数组
 */
function moveBackwardInPlaceOptimized(arr, k) {
  if (k >= arr.length || k <= 0) {
    throw new Error('K必须大于0且小于数组长度');
  }

  // 关键：从后往前移动，一次性完成移动和填充
  for (let i = arr.length - 1; i >= 0; i--) {
    if (i >= k) {
      arr[i] = arr[i - k];  // 移动元素
    } else {
      arr[i] = '';  // 填充空字符串
    }
  }

  return arr;
}

// 使用示例
const arr7 = ['a', 'b', 'c', 'd', 'e'];
console.log('原数组:', [...arr7]);
console.log('向后移动2位:', moveBackwardInPlaceOptimized(arr7, 2));
// 输出: ['', '', 'a', 'b', 'c']
```

### 原地操作的使用场景

#### 适合使用原地操作的场景：
1. **内存敏感的环境**：如嵌入式系统、移动设备
2. **大数组处理**：避免创建额外的大数组
3. **性能要求高**：减少内存分配和垃圾回收
4. **不需要保留原数组**：原数组可以被修改

#### 不适合使用原地操作的场景：
1. **需要保留原数组**：原数组需要在其他地方使用
2. **函数式编程风格**：追求不可变性
3. **调试和测试**：原地操作难以调试和验证
4. **多线程环境**：原地操作可能导致竞态条件

### 总结

1. **向前移动**：可以从前往后处理，因为读取位置在写入位置之后，不会覆盖未处理的数据
2. **向后移动**：必须从后往前处理，因为如果从前往后会覆盖还未读取的数据
3. **原地操作**：节省内存但会修改原数组，需要根据具体场景选择
4. **覆盖问题**：理解数据流向是关键，避免在读取数据之前就被覆盖

这就是为什么在原地操作中，向后移动必须从后往前处理的根本原因：**保护数据不被覆盖**。

## 扩展功能

### 支持循环移动（可选）

```javascript
/**
 * 数组循环向前移动K位
 * @param {Array} arr - 原数组
 * @param {number} k - 移动位数
 * @returns {Array} - 移动后的新数组
 */
function moveForwardCircular(arr, k) {
  k = k % arr.length; // 处理k大于数组长度的情况
  return [...arr.slice(k), ...arr.slice(0, k)];
}

/**
 * 数组循环向后移动K位
 * @param {Array} arr - 原数组
 * @param {number} k - 移动位数
 * @returns {Array} - 移动后的新数组
 */
function moveBackwardCircular(arr, k) {
  k = k % arr.length; // 处理k大于数组长度的情况
  return [...arr.slice(-k), ...arr.slice(0, -k)];
}

// 循环移动示例
const circularArray = [1, 2, 3, 4, 5];
console.log('循环向前移动2位:', moveForwardCircular(circularArray, 2));
// 输出: [3, 4, 5, 1, 2]
console.log('循环向后移动2位:', moveBackwardCircular(circularArray, 2));
// 输出: [4, 5, 1, 2, 3]
```

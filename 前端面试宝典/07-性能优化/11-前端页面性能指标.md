# 前端页面性能指标详解

## 核心性能指标

### 1. 白屏时间 (First Paint, FP)

**定义**：
白屏时间是指从用户访问页面到浏览器开始绘制第一个像素的时间。这是用户感知页面加载速度的第一个重要指标，也是用户对网站性能的第一印象。

**意义**：
白屏时间直接影响用户体验，过长的白屏时间会导致用户流失。研究表明，页面加载时间每增加1秒，转化率可能下降7%。

**计算方法**：
使用 Paint Timing API 计算：

```javascript
const fp = performance.getEntriesByType('paint')[0]?.startTime || 0;
console.log(`白屏时间: ${fp.toFixed(2)} ms`);
```

**影响因素**：
- 服务器响应时间
- 网络传输速度
- HTML文档大小和解析速度
- 关键CSS加载和解析

**优化策略**：
- 服务端渲染(SSR)或静态站点生成(SSG)
- 使用CDN加速静态资源
- 优化关键CSS，使用内联CSS
- 减少HTML文档大小
- 启用HTTP/2或HTTP/3

### 2. 首次内容绘制 (First Contentful Paint, FCP)

**定义**：
FCP 衡量的是页面首次绘制任何文本、图像、非白色背景等内容的时间。它标志着用户开始看到页面内容，而不仅仅是空白屏幕。

**意义**：
FCP是用户体验的关键指标，它告诉我们页面是否正在加载中。良好的FCP体验能让用户更有耐心等待页面完全加载。

**计算方法**：
使用 Paint Timing API 计算：

```javascript
const fcp = performance.getEntriesByType('paint').find(entry => entry.name === 'first-contentful-paint')?.startTime || 0;
console.log(`首次内容绘制时间: ${fcp.toFixed(2)} ms`);
```

**目标值**：
- 良好：≤1.8秒
- 需改进：1.8-3秒
- 差：>3秒

**影响因素**：
- 首屏关键资源加载速度
- 字体加载策略
- 图片优化
- 渲染阻塞资源

**优化策略**：
- 优先加载首屏内容
- 使用适当的字体加载策略(如font-display)
- 图片懒加载
- 优化和内联关键CSS
- 延迟加载非关键JavaScript

### 3. 可交互时间 (Time to Interactive, TTI)

**定义**：
TTI 衡量的是页面布局已稳定、关键的资源已加载完成、且用户可以与页面进行交互的时间。此时，页面响应用户输入的延迟应在50毫秒以内。

**意义**：
TTI标志着页面从视觉加载完成到功能完全可用的时间，是衡量页面交互性能的重要指标。

**计算方法**：
TTI的计算相对复杂，以下是一个简化版本：

```javascript
function calculateTTI() {
  // 查找稳定交互期的起始点
  const navigationEntry = performance.getEntriesByType('navigation')[0];
  const domContentLoaded = navigationEntry.domContentLoadedEventEnd;
  const loadEvent = navigationEntry.loadEventEnd;
  
  // 简化计算：使用DOMContentLoaded事件结束时间作为TTI的近似值
  console.log(`可交互时间: ${domContentLoaded.toFixed(2)} ms`);
}

document.addEventListener('load', calculateTTI);
```

**目标值**：
- 良好：≤3.8秒
- 需改进：3.8-7秒
- 差：>7秒

**影响因素**：
- JavaScript执行时间
- 第三方脚本加载
- 主线程阻塞时间
- 资源加载顺序

**优化策略**：
- 代码分割和懒加载
- 优化JavaScript执行效率
- 减少第三方脚本
- 使用Web Workers处理复杂计算
- 优化渲染阻塞资源

## 其他重要指标

### 4. 最大内容绘制 (Largest Contentful Paint, LCP)

**定义**：
LCP 衡量的是视口中最大的内容元素渲染完成的时间，这是衡量加载性能的核心指标。最大内容通常是图片、视频或大段文本。

**意义**：
LCP反映了页面主要内容的加载速度，是用户判断页面是否可用的重要依据。

**计算方法**：

```javascript
new PerformanceObserver((entryList) => {
  for (const entry of entryList.getEntries()) {
    console.log(`最大内容绘制时间: ${entry.startTime.toFixed(2)} ms`);
  }
}).observe({ type: 'largest-contentful-paint', buffered: true });
```

**目标值**：
- 良好：≤2.5秒
- 需改进：2.5-4秒
- 差：>4秒

**影响因素**：
- 最大元素的大小和加载时间
- 服务器响应时间
- 网络条件
- 缓存策略

**优化策略**：
- 优化图片加载(压缩、适当格式、懒加载)
- 预加载关键资源
- 使用CDN
- 优化服务器响应
- 实现适当的缓存策略

### 5. 首次输入延迟 (First Input Delay, FID)

**定义**：
FID 衡量的是用户第一次与页面交互（点击链接、按钮等）到浏览器实际开始处理该交互之间的时间差。

**意义**：
FID反映了页面的交互响应性，直接影响用户体验。过长的延迟会让用户感觉页面卡顿。

**计算方法**：

```javascript
new PerformanceObserver((entryList) => {
  for (const entry of entryList.getEntries()) {
    if (entry.interactionType !== 'none') {
      console.log(`首次输入延迟: ${entry.processingStart - entry.startTime} ms`);
    }
  }
}).observe({ type: 'first-input', buffered: true });
```

**目标值**：
- 良好：≤100毫秒
- 需改进：100-300毫秒
- 差：>300毫秒

**影响因素**：
- JavaScript执行阻塞
- 主线程繁忙
- 事件处理程序复杂度
- 第三方脚本

**优化策略**：
- 减少JavaScript执行时间
- 拆分长任务
- 使用Web Workers
- 优化事件处理程序
- 延迟加载非关键JavaScript

### 6. 累积布局偏移 (Cumulative Layout Shift, CLS)

**定义**：
CLS 衡量的是页面在生命周期内发生的意外布局偏移的总和，反映了页面的视觉稳定性。它通过计算每次布局偏移的影响分数和距离分数的乘积来得到。

**意义**：
CLS低的页面给人感觉更稳定、更专业。高CLS会导致用户误操作，降低用户体验。

**计算方法**：

```javascript
let cumulativeLayoutShift = 0;

new PerformanceObserver((entryList) => {
  for (const entry of entryList.getEntries()) {
    if (!entry.hadRecentInput) {
      cumulativeLayoutShift += entry.value;
      console.log(`当前累积布局偏移: ${cumulativeLayoutShift.toFixed(4)}`);
    }
  }
}).observe({ type: 'layout-shift', buffered: true });
```

**目标值**：
- 良好：≤0.1
- 需改进：0.1-0.25
- 差：>0.25

**影响因素**：
- 图片和视频没有设置尺寸
- 动态加载内容
- 字体加载导致的文本重排
- CSS动画和过渡

**优化策略**：
- 为媒体元素设置明确的尺寸
- 使用aspect-ratio属性
- 预加载关键字体
- 避免动态注入内容到视口顶部
- 优化CSS动画

### 7. 首次有意义绘制 (First Meaningful Paint, FMP)

**定义**：
FMP 衡量的是页面上有意义内容首次出现的时间。有意义内容通常指对用户来说最重要的内容，如主标题、主要图像等。

**计算方法**：
FMP没有标准API，通常需要结合其他指标和业务逻辑来计算：

```javascript
// 示例：监控特定元素的出现时间作为FMP
function observeFMP() {
  const targetElement = document.querySelector('.main-content');
  if (targetElement) {
    const rect = targetElement.getBoundingClientRect();
    if (rect.width > 0 && rect.height > 0) {
      const fmp = performance.now();
      console.log(`首次有意义绘制时间: ${fmp.toFixed(2)} ms`);
      return true;
    }
  }
  return false;
}

// 轮询检查直到FMP完成
function checkFMP() {
  if (!observeFMP()) {
    requestAnimationFrame(checkFMP);
  }
}

window.addEventListener('load', checkFMP);
```

### 8. 交互到下一次绘制 (Interaction to Next Paint, INP)

**定义**：
INP 衡量的是用户交互（点击、滚动、键盘输入等）到浏览器完成下一次绘制之间的时间。它关注的是页面在整个生命周期内的交互响应性。

**计算方法**：

```javascript
new PerformanceObserver((entryList) => {
  for (const entry of entryList.getEntries()) {
    console.log(`交互到下一次绘制时间: ${entry.duration.toFixed(2)} ms`);
  }
}).observe({ type: 'event', buffered: true });
```

**目标值**：
- 良好：≤200毫秒
- 需改进：200-500毫秒
- 差：>500毫秒

## 性能监控实践

### 使用 Performance API 监控

```javascript
/**
 * @description 全面监控前端性能指标
 */
function monitorPerformance() {
  // 监控 FP 和 FCP
  const paintObserver = new PerformanceObserver((entryList) => {
    entryList.getEntries().forEach(entry => {
      console.log(`${entry.name}: ${entry.startTime.toFixed(2)} ms`);
      // 可以在这里上报性能数据到服务器
    });
  });
  paintObserver.observe({ type: 'paint', buffered: true });

  // 监控 LCP
  const lcpObserver = new PerformanceObserver((entryList) => {
    entryList.getEntries().forEach(entry => {
      console.log(`LCP: ${entry.startTime.toFixed(2)} ms`);
    });
  });
  lcpObserver.observe({ type: 'largest-contentful-paint', buffered: true });

  // 监控 FID
  const fidObserver = new PerformanceObserver((entryList) => {
    entryList.getEntries().forEach(entry => {
      if (entry.interactionType !== 'none') {
        const fid = entry.processingStart - entry.startTime;
        console.log(`FID: ${fid.toFixed(2)} ms`);
      }
    });
  });
  fidObserver.observe({ type: 'first-input', buffered: true });

  // 监控 CLS
  let cls = 0;
  const clsObserver = new PerformanceObserver((entryList) => {
    entryList.getEntries().forEach(entry => {
      if (!entry.hadRecentInput) {
        cls += entry.value;
        console.log(`CLS: ${cls.toFixed(4)}`);
      }
    });
  });
  clsObserver.observe({ type: 'layout-shift', buffered: true });

  // 监控 Navigation Timing
  window.addEventListener('load', () => {
    const navEntry = performance.getEntriesByType('navigation')[0];
    console.log('DNS查询时间:', navEntry.domainLookupEnd - navEntry.domainLookupStart);
    console.log('TCP连接时间:', navEntry.connectEnd - navEntry.connectStart);
    console.log('请求响应时间:', navEntry.responseEnd - navEntry.requestStart);
    console.log('DOM解析时间:', navEntry.domComplete - navEntry.domInteractive);
    console.log('页面加载总时间:', navEntry.loadEventEnd - navEntry.startTime);
  });
}

// 启动监控
monitorPerformance();
```

### 性能数据上报

```javascript
/**
 * @description 上报性能数据到服务器
 * @param {Object} metrics - 性能指标数据
 */
function reportPerformanceData(metrics) {
  try {
    // 使用Fetch API异步上报
    fetch('/api/performance-report', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(metrics),
      // 不阻塞主线程
      keepalive: true
    });
  } catch (error) {
    console.error('性能数据上报失败:', error);
  }
}

// 示例：收集并上报数据
function collectAndReport() {
  const metrics = {
    timestamp: Date.now(),
    url: window.location.href,
    userAgent: navigator.userAgent
    // 这里可以添加更多性能指标
  };

  // 收集Paint指标
  const paintEntries = performance.getEntriesByType('paint');
  paintEntries.forEach(entry => {
    metrics[entry.name] = entry.startTime;
  });

  // 收集Navigation指标
  const navEntry = performance.getEntriesByType('navigation')[0];
  if (navEntry) {
    metrics.domContentLoaded = navEntry.domContentLoadedEventEnd;
    metrics.loadTime = navEntry.loadEventEnd;
  }

  // 上报数据
  reportPerformanceData(metrics);
}

// 页面加载完成后上报
window.addEventListener('load', collectAndReport);
```

### 性能优化建议

1. **减少白屏时间**：
   - 实现服务端渲染或静态站点生成
   - 使用CDN加速静态资源
   - 优化关键CSS，将其内联到HTML
   - 减少HTML文档大小，移除不必要的注释和空白
   - 启用HTTP/2或HTTP/3协议
   - 实现资源预加载(preload)

2. **提升 FCP**：
   - 优先加载首屏关键内容
   - 使用适当的字体加载策略，如font-display: swap
   - 图片懒加载，只加载视口内的图片
   - 优化和内联关键CSS
   - 延迟加载非关键JavaScript
   - 使用WebP或AVIF等高效图片格式

3. **改善 TTI**：
   - 代码分割，只加载当前页面所需的JavaScript
   - 优化JavaScript执行效率，减少长任务
   - 减少第三方脚本的使用
   - 使用Web Workers处理复杂计算
   - 优化渲染阻塞资源
   - 实现资源优先级加载

4. **优化 LCP**：
   - 优化图片大小和格式
   - 实现图片预加载
   - 使用适当的缓存策略
   - 确保服务器响应迅速
   - 优化字体加载
   - 避免布局偏移影响主要内容

5. **减少 FID**：
   - 减少主线程阻塞时间
   - 拆分长任务为多个短任务
   - 使用Web Workers处理数据处理任务
   - 优化事件监听器
   - 延迟加载非关键JavaScript
   - 优化第三方脚本

6. **降低 CLS**：
   - 为所有媒体元素设置明确的宽度和高度
   - 使用aspect-ratio属性保持宽高比
   - 预加载字体并使用适当的字体显示策略
   - 避免在视口顶部动态注入内容
   - 使用占位符或骨架屏
   - 优化CSS动画，避免 layout thrashing

## 测量工具

### 浏览器内置工具
- **Chrome DevTools**：提供Performance面板，可以记录和分析页面加载性能
- **Firefox Developer Tools**：包含Performance面板和Network监控
- **Safari Web Inspector**：提供Timelines和Network监控功能

### 自动化工具
- **Lighthouse**：Google开发的开源工具，可审计网页性能、可访问性等
- **WebPageTest**：提供详细的性能测试报告，支持全球多个测试节点
- **Calibre**：持续性能监控平台，支持自动化测试和报告
- **New Relic**：应用性能监控工具，提供实时性能数据

### 自建监控系统
- 基于Performance API自定义监控
- 结合日志系统分析性能数据
- 实现性能告警机制

> Tip: 可结合 Chrome DevTools 的 Performance 面板、Lighthouse 审计工具和自建监控系统，形成完整的性能监控和优化体系。定期分析性能数据，持续优化用户体验。
